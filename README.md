# LKP

🏫 LPK – Site Vitrine du Lycée Privé KENNTNIS

Site web vitrine responsive pour le Lycée Privé KENNTNIS (LPK) à Bobo-Dioulasso, Burkina Faso. Présente les formations générales, techniques et professionnelles pour l'année scolaire 2026-2027.



✨ Fonctionnalités

· Menu de navigation fixe et fluide
· Présentation des 3 filières (Général, Technique, Professionnel)
· Conditions d'admission et formulaire de contact
· Galerie interactive filtrable par catégorie
· Actualités sous forme de cartes
· Boutons flottants (Appel / WhatsApp)
· Animations au défilement
· 100% responsive (mobile, tablette, desktop)



🛠️ Technologies

· HTML5 / CSS3 / JavaScript vanilla
· Font Awesome pour les icônes
· Police Montserrat (Google Fonts)


🚀 Utilisation

1. Téléchargez ou clonez le dépôt.
2. Ouvrez le fichier index.html dans votre navigateur.
3. Personnalisez les textes, couleurs et coordonnées selon vos besoins.
